# Fincake Downloads

Fincake is free to use. Download the latest official Android APK:

[Download Fincake.apk](https://github.com/Cake-Development/Fincake-Downloads/releases/download/apk-latest/Fincake.apk)

The `apk-latest` link is kept current when a new release is published. Older releases are listed separately in [Releases](https://github.com/Cake-Development/Fincake-Downloads/releases).

Fincake is not distributed through Google Play yet. Android may ask you to confirm installation of an APK downloaded outside the Play Store. Only install APKs you intended to download. APK files can be inspected or reverse-engineered; this repository contains release files and public policy pages, not the app's source project.
